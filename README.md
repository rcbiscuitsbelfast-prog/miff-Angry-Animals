# Angry Animals

A Godot 4.x (C#) physics puzzle game with procedural generation,
multi-material obstacles, and cross-platform support.

## Quick Start

1. Clone the repo
2. Open in Godot 4.x Mono
3. Press Play (▶) to run
4. Select "Start Game" from Main Menu

## Key Features

- ✅ 5-material hardness system (Wood 1 → Diamond 5)
- ✅ Intelligent procedural generation by difficulty
- ✅ NPC cosmetics system
- ✅ Cross-platform (Windows, macOS, Linux, iOS, Android)
- ✅ 100+ procedural levels + hand-crafted levels

## Project Structure

- `Scenes/` - All .tscn scene files
- `Scripts/` - All C# code
- `Assets/` - Sprites, audio, fonts
- `Globals/` - Singleton managers
- `Docs/` - Documentation (guides, checklists, design)
