# Daily Challenge System Setup

The Daily Challenge system provides a fresh, deterministic procedural level every day for all players.

## Mechanics

- **Seeded Generation**: The level seed is derived from the current date (YYYYMMDD). This ensures every player in the world plays the exact same level on any given day.
- **Level Selection**: The "room number" for the procedural generator is also derived from the date, providing variety in themes and difficulty.
- **Access**: Available via the "Daily Challenge" button on the Main Menu.

## Reset Cycle

The challenge resets automatically at **00:00 UTC**.

## Rewards & Retention

Completing the Daily Challenge rewards the player with a unique "Excited" head expression and adds to their personal leaderboard stats.
