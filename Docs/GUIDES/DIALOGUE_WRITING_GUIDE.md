# 🗣️ DIALOGUE WRITING GUIDE
## Create Memorable Characters Without Code

> **TL;DR:** Write compelling dialogue for NPCs using Inspector settings. Create characters that players will remember and love.

### Add Custom Dialogue to Mom:
```
1. Open any level with MomNPC
2. Select MomNPC node
3. Inspector → dialogue property
4. Replace existing lines:
   ["WATCH IT, KIDDO!", "No games today!", "Study first!"]
5. Save → Test
Result: Mom now says your custom lines!
```

## 🎭 CHARACTER PERSONALITY GUIDE

### Family Characters (Mom, Dad)
```
Mom Personality:
- Protective and commanding
- Uses caring language that sounds controlling
- Examples: "WATCH IT!", "Clean your room!", "Not my rules!"

Dad Personality:
- Authoritative with financial references
- Uses "I pay for this house" type lines
- Examples: "MY rules!", "Go OUTSIDE!", "I pay for this house!"

Writing Tips:
- Use exclamation points for authority
- Include family-specific phrases
- Make it relatable to real experiences
```

### Authority Characters (Teacher, Principal, Soldier)
```
Teacher Personality:
- Educational and disciplinary
- Uses detention/threat language
- Examples: "DETENTION!", "This is UNACCEPTABLE!", "Your parents will hear about this!"

Soldier Personality:
- Military and commanding
- Uses tactical/emergency language
- Examples: "INTRUDER!", "CODE RED!", "SURRENDER NOW!"

Principal Personality:
- Ultimate school authority
- Uses formal disciplinary language
- Examples: "To my office!", "This ends NOW!", "You're expelled!"

Writing Tips:
- Make authority clear through word choice
- Use formal or commanding language
- Include institutional references
```

### Peer Characters (Schoolmates, Friends)
```
Schoolmate Personality:
- Helpless and pleading
- Uses peer-level language
- Examples: "HELP!", "Get me out!", "I didn't do anything!"

Friend Personality:
- Casual and supportive
- Uses friendly language
- Examples: "Hey dude!", "That's awesome!", "Let's do this!"

Writing Tips:
- Use casual, peer-appropriate language
- Include "helpless" emotions for trapped characters
- Make it relatable to school experiences
```

## 📝 DIALOGUE WRITING TEMPLATES

### Template 1: Authority Figure
```
Structure: [Command] + [Reason] + [Threat]

Examples:
- "BEHAVE!" + "This is my classroom!" + "Or face consequences!"
- "DETENTION!" + "Your behavior is unacceptable!" + "Your parents will hear!"
- "STOP RIGHT THERE!" + "This is military property!" + "Or face arrest!"

Writing Formula:
1. Start with commanding verb
2. Add reason/justification
3. End with consequence/threat
```

### Template 2: Family Member
```
Structure: [Relationship] + [Rule] + [Enforcement]

Examples:
- "I'm your mother!" + "You will respect my rules!" + "Or no games!"
- "I pay for this house!" + "MY rules apply here!" + "Understand?"
- "Family comes first!" + "You represent us!" + "Act accordingly!"

Writing Formula:
1. Establish relationship/authority
2. State the rule clearly
3. Add enforcement mechanism
```

### Template 3: Trapped Character
```
Structure: [Situation] + [Request] + [Justification]

Examples:
- "I'm trapped!" + "Please help me out!" + "I didn't do anything!"
- "This is insane!" + "Get me out of here!" + "I don't belong here!"
- "HELP!" + "Someone please help!" + "I'm innocent!"

Writing Formula:
1. Acknowledge the situation
2. Make a clear request
3. Provide justification for help
```

## 🎨 HUMOR TECHNIQUES

### Absurdist Humor
```
Technique: Escalate normal situations to ridiculous extremes

Examples:
Normal: "Clean your room"
Escalated: "Clean your room! THE UNIVERSE DEPENDS ON IT!"

Normal: "Go to bed"
Escalated: "Go to bed! THE FATE OF HUMANITY IS AT STAKE!"

Normal: "Pay attention"
Escalated: "PAY ATTENTION! THE FUTURE OF CIVILIZATION HANGS IN THE BALANCE!"

Writing Method:
1. Start with normal command
2. Add escalating reason
3. End with absurd consequence
```

### Irony and Contradiction
```
Technique: NPCs say the opposite of what they mean

Examples:
- "Everything is perfectly fine" (while chaos happens)
- "This is completely normal" (while something weird occurs)
- "I have complete control" (while losing control)

Writing Method:
1. State control/sanity
2. Show opposite through situation
3. Let players notice the contradiction
```

### Deadpan Delivery
```
Technique: NPCs say extreme things in calm, matter-of-fact tone

Examples:
- "I will now destroy your entire existence" (casually)
- "This is the end of everything as we know it" (calmly)
- "Reality itself is ending" (matter-of-factly)

Writing Method:
1. Write extreme statements
2. Deliver in calm voice
3. Let humor come from contrast
```

## 🛠️ IMPLEMENTATION GUIDE

### Adding Dialogue to NPCs
```
Step 1: Open any level with an NPC
Step 2: Select the NPC node
Step 3: Find "dialogue" property in Inspector
Step 4: Add or replace dialogue lines:
   - Click "Add Element" to add lines
   - Type your custom dialogue
   - Use commas to separate multiple lines
Step 5: Save (Ctrl+S)
Step 6: Test in game (F5)
```

### Dialogue Testing
```
Quick Test Method:
1. Add one line of dialogue
2. Test in game
3. Check if speech bubble appears
4. Verify text is readable
5. Adjust timing if needed
6. Add more lines gradually

Quality Check:
- Read dialogue aloud
- Check for typos
- Ensure personality consistency
- Test different game states
```

### Performance Optimization
```
Keep Lines Short:
- Maximum 50 characters per line
- Use common words
- Avoid complex sentences

Limit Line Count:
- 5-10 lines per character
- Rotate lines to avoid repetition
- Use random selection

Timing Considerations:
- 3-5 seconds between lines
- Longer for complex humor
- Shorter for simple commands
```

## 🎯 BEST PRACTICES

### Character Consistency
```
Maintain Personality:
- Each character should have distinct voice
- Use consistent language patterns
- Avoid mixing character types

Example:
Mom always uses protective language
Dad always references financial authority
Teacher always uses educational terms
Soldier always uses military language
```

### Player Engagement
```
Make Dialogue Interactive:
- Reference player actions
- Comment on game events
- React to perfect scores
- Acknowledge failures

Example Responses:
Perfect Score: "How did you DO that?!"
Failure: "Maybe try actually aiming..."
Chaos: "What have you DONE to reality?!"
```

### Humor Timing
```
Placement Matters:
- Authority figures: Speak frequently
- Trapped characters: Speak when player nearby
- Background characters: Speak occasionally

Avoid Over-saturation:
- Don't interrupt gameplay
- Let players focus on physics
- Use dialogue to enhance, not distract
```
