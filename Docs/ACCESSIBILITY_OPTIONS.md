# Accessibility Features

Angry Animals is designed to be inclusive and playable by everyone.

## Visual Accessibility
- **Colorblind Mode**: Switches to high-contrast palettes for UI and physics objects.
- **Text Scaling**: UI text can be scaled from 100% to 150%.
- **High Contrast**: Increases visibility of projectiles and targets against backgrounds.
- **Reduce Motion**: Disables screen shake, camera zooms, and fast UI animations.

## Difficulty Accessibility
- **Difficulty Presets**:
  - **Easy**: Larger targets, slower projectile decay, 50% target scores.
  - **Normal**: Standard experience.
  - **Hardcore**: Smaller targets, faster decay, 150% target scores.

## Configuration
All options are available in the **Settings Menu** and persist in the player profile.
